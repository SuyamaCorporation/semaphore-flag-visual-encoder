# 手旗信号セマフォービジュアルエンコーダー

テキストをISO手旗信号（セマフォー）に変換してSVG人形アニメーションで表示するツール。逆デコードクイズ付き。

## 概要

SVGで腕の角度を変える人形アニメーション（45°刻み8方向）でセマフォーを表現。A-Zの各文字の手旗角度データをハードコードし、入力テキストを文字ごとに順次アニメーション表示する。クイズモードでは人形の姿勢を見て文字を当てる。

## 機能

- **エンコードモード**: A-Zのテキストを入力→セマフォーアニメーション再生
- **速度スライダー**: アニメーション速度を調整（速い〜超ゆっくり）
- **クイズモード**: 人形の姿勢を見て6択で文字を当てる、スコア累計
- **参照テーブル**: 画面下部に全文字の角度データ一覧（左手角度/右手角度）

## セマフォー仕様

- ISO標準手旗信号を採用（左腕・右腕それぞれ0°〜315°の45°刻み8方向）
- スペース文字は両腕を真下（rest position）で表現
- 人形SVGは頭・胴体・脚に加え、両腕先端に赤旗を表示

## 技術仕様

- バニラJS + SVG DOM操作
- 三角関数による腕先端座標計算
- setTimeoutによる逐次アニメーション制御
